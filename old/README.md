# old stuff

this folder contains some of copyparty plugins I used separately before 
converting them into a single `fpkg-vault` thing

[fpkg-thumb](./fpkg_thumb.py) – thumbnail extractor pluggable to copyparty with `--th-extract pkg=fpkg_thumb.py`
[fpkgi-server](./pkgi.py) – fpkgi-server initially named `copyparty-dumb-fpkgi-handler`; pluggable to copyparty via `--on404 pkgi.py`

this stuff is UNLICENSED so do with it whatever you want

the advantage of these files is that you can plug them in separately and independently
taking only parts you need
